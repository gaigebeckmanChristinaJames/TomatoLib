# 通用模块 / APP WebUI 复刻提示词（纯文本）

> 用法：把本文件从「一、任务」到「十、验收」整段复制给任意 AI。不要只复制片段；第 3、7 节是像素级基准，缺一节就会走样。
> 目标不是“做一个类似的暗色界面”，而是**产出与基准样张同一套设计语言、同一组尺寸、同一套交互时序的 UI**。只允许替换文案、数据与业务命令，不允许替换视觉结构。

---

## 一、任务

你是系统工具类移动端 UI 设计师与前端工程师。为 `{{APP_NAME}}`（一个 KernelSU / Magisk 模块 WebUI，或一个 Android 工具 App）实现一套高信息密度、黑白灰、细边框卡片的界面。

产物要求：
- WebUI：**单个自包含 HTML 文件**，CSS 与 JS 全部内联，不依赖 React/Vue/构建工具，不依赖外部图片与字体。
- 原生 App：按第 8 节映射表实现 Compose / Flutter 版本，令牌、尺寸、层级、时序与 WebUI 完全一致。
- 至少 4 个页面，每页 2–5 张卡片；必须有左侧抽屉、底部位置胶囊、Toast、底部 Sheet。
- 所有按钮、开关、导航项必须能点击并有真实反馈，禁止僵尸按钮。

---

## 二、不可协商的硬约束

1. **颜色只能来自 CSS 变量**。除皮肤定义外，任何地方不得出现写死的 hex、rgb、hsl。
2. **不做渐变、发光边框、玻璃拟态装饰、插画、循环动画、粒子、emoji**。
3. 卡片 = `1px 边框 + 圆角 + 极轻投影`，不是“大圆角 + 厚阴影 + 渐变图标”。
4. 强调色只出现在：开关开启、档位选中、当前导航竖条、进度填充、少量状态点。其余保持黑白灰。
5. 字体只用一个系统无衬线栈；层级靠字号、字重、字距、颜色，不靠换字体。
6. 数字必须 `font-variant-numeric: tabular-nums`，大数字字距收紧。
7. 所有触控目标不小于 30px；底部必须留 `env(safe-area-inset-bottom)`。
8. 动效只允许 `opacity` 与 `transform`；时长与曲线照第 6 节，不得自创弹跳。
9. 抽屉、卡片、开关、按钮、输入、档位、分段时间、Sheet、Toast 的尺寸照第 5 节，误差不超过 1px。
10. 页面标题、卡片标题、列表标签的中文文案必须短、动词开头、状态如实；成功加 `✓`，失败必须带原因。
11. `<meta name="viewport" content="width=device-width,initial-scale=1,viewport-fit=cover">`；禁止 `maximum-scale=1` 或 `user-scalable=no`。

## 六、交互与时序（必须逐条实现）

1. 抽屉打开：`transform: translateX(-104%) → none`，**440ms**，`cubic-bezier(.22,.8,.28,1)`；遮罩 340ms。
2. 分组展开：`max-height 0 → scrollHeight`，**460ms**，同曲线；同一时间只开一组。
3. 二级项入场：`opacity 0 / translateX(-16px) → 1 / 0`，**320ms**，延迟 `60ms + i*45ms`。
4. 开关：180ms；先 `busy`（opacity .55、禁点），260ms 后落盘并回读，再 `on`。
5. Toast：180ms 淡入上移；3.2s 后淡出。
6. 位置胶囊：滚动停止后出现，260ms；2.4s 后淡出。
7. 页面切换：横向 `scroll-snap`，不得改成纵向列表；滚动停止后同步抽屉高亮与胶囊。
8. 主题切换：`html.light` 类；皮肤切换：`html[data-skin]`；两者都持久化。
9. 所有设置落盘，重启后回读；读取失败显示 `—`，不得显示假值。
10. 日志长输出分段读取，避免内核 `exec` 截断；尾部必须能看到结束标记。

## 八、适配任意模块 / 原生 App

### 8.1 WebUI：只改 3 个地方

| 位置 | 改什么 | 不改什么 |
| --- | --- | --- |
| `Bridge` | 模块的读/写/执行实现 | 调用方式与 UI |
| `NAV_META` / 页面 `<h2>` | 页面名称与图标 | 页面结构、卡片结构 |
| 卡片内容 | 标签、数值、开关 key | class、尺寸、动效 |

统一桥接层（7.5 顶部已给出兜底定义，接入模块时**只替换函数体**）：

```js
/* 7.5 已定义 const Bridge = window.Bridge || {...}，这里只示意方法签名 */
Bridge.get(key)      // 返回字符串；失败返回 null
Bridge.set(key,val)  // 写 settings.txt 并回读；返回 {ok,msg}
Bridge.exec(cmd)     // 返回 {code,stdout,stderr}；长日志分页读
```

接入 KernelSU / Magisk 时，把 `get` 改为读 `settings.txt`，`set` 改为写 `settings.txt` 并回读，`exec` 改为模块的 `exec` 命令；失败返回 `null` 或 `{code:-1}`，UI 据此显示 `—` 与错误 Toast。

推荐状态对象：

```json
{
  "device": {"model":"{{MODEL}}","chip":"{{CHIP}}","os":"{{OS}}","battery":84,"temp":38.6},
  "settings": {"fan_level":4,"smart_fan":true,"charge_limit":80},
  "runtime": {"service":"running","pid":33194,"version":"{{VERSION}}"},
  "pages": [{"title":"{{PAGE_1}}","cards":[{"title":"{{CARD_1}}"}]}]
}
```

读取失败必须显示 `—`，禁止用示例值冒充真实值。

### 8.2 原生 App 映射

| WebUI | Compose | Flutter |
| --- | --- | --- |
| 卡片 1px 边框、圆角 1rem、无阴影 | `Surface(shape=RoundedCornerShape(16.dp), border=BorderStroke(1.dp, border), color=card)` | `Container(decoration: BoxDecoration(color: card, borderRadius: BorderRadius.circular(16), border: Border.all(color: border)))` |
| 顶栏 58px 毛玻璃 | `TopAppBar` 高 58.dp + `Modifier.blur(18.dp)` 背景层 | `Container(height:58, BackdropFilter(blur:18))` |
| 抽屉 286px | `ModalNavigationDrawer` 宽 286.dp | `Drawer(width:286)` |
| 开关 44×26 | 自绘 `Box` + `animateFloatAsState` 180ms | 自绘 `AnimatedContainer` 180ms |
| 按钮 34px | `Button(contentPadding=PaddingValues(14.dp,0.dp), modifier=height(34.dp))` | `SizedBox(height:34)` |
| 输入 32px | `OutlinedTextField` 高 32.dp | `TextField` 高度 32 |
| Toast | 底部 `Snackbar` 自定义背景/圆角 | 自定义 `OverlayEntry` |

原生端同样只用第 3 节令牌；不得换成 Material 默认紫色、默认阴影、默认圆角。

### 8.3 原生端必须保留

- 五套皮肤的等价主题（至少深/浅 + 一个强调色变体）。
- 抽屉分组/子项层级、当前项竖条、位置胶囊。
- 卡片 1px 边框、16px 内边距、12px 间距。
- 开关 44×26、按钮 34、输入 32、档位 32、分段时间 38。
- 440ms 抽屉、460ms 分组、45ms 子项递增延迟。

## 九、常见失败与修正

| 失败 | 修正 |
| --- | --- |
| 做成 SaaS 大圆角卡片 + 渐变图标 | 删除渐变与图标底色；卡片只留 1px 边框 + 16px 圆角 |
| 强调色铺满按钮/标题 | 强调色只给开关、选中档位、当前导航竖条、进度 |
| 抽屉做成常驻侧栏 | 必须覆盖式，默认 `translateX(-104%)` |
| 导航手写死列表 | 必须从 `.card h3` 生成，保证页面与导航一致 |
| 所有卡片一样大、无信息层级 | 用读数、列表、进度、开关四类卡片组织，不要全是同构卡片 |
| 动效全站淡入上滑 | 只保留抽屉、分组、子项、Toast、胶囊五处 |
| 小屏文字挤成一字宽 | 卡片与列表加 `min-width:0`；360px 断点隐藏副标题与版本徽章 |
| 用示例数据冒充真实读数 | 读取失败显示 `—`，并给出 Toast 原因 |
| 按钮无 handler | 每个入口必须绑定真实函数或明确 Toast |

## 十、验收（逐项打勾，缺一不算完成）

- [ ] 单文件 HTML，可直接打开，无外部依赖、无构建步骤。
- [ ] 深色/浅色可切换；五套皮肤可切换；刷新后保持。
- [ ] 顶栏 58px，Logo 34，版本徽章 21，图标按钮 34。
- [ ] 卡片 1px 边框、`--r` 圆角、16px 内边距、12px 间距、极轻投影。
- [ ] 开关 44×26、滑块 20、位移 18；按钮 34；输入 32；档位 32；分段时间 38。
- [ ] 抽屉 286px/84vw，一级 44、二级 33，当前分组竖条 3px。
- [ ] 抽屉 440ms、分组 460ms、子项 320ms 且 45ms 递增延迟。
- [ ] 位置胶囊显示“大类 + 二级项 + n/N”，滚动停止出现、2.4s 消失。
- [ ] Toast 180ms、3.2s 消失；错误红色且带原因。
- [ ] Sheet 最大 82vh、圆角 16、底部对齐。
- [ ] 至少 4 页，每页 2–5 张卡片；导航与页面滚动双向同步。
- [ ] 360px 与 430px 宽均无横向溢出；长英文/长路径不撑破卡片。
- [ ] 数字全部等宽；大数字字距 -0.6 ~ -0.8px。
- [ ] 除皮肤定义外无写死颜色；无渐变、无发光、无插画、无 emoji。
- [ ] 所有按钮、开关、导航项都有真实反馈，无僵尸按钮。
- [ ] 设置真实落盘并在重启后回读；失败显示 `—` 与错误原因。

**最终自检**：把成品与第 4 节骨架、第 5 节尺寸表逐项对照；任何一项偏差超过 1px，都视为未复刻。
